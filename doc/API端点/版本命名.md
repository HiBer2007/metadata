# FLF API 版本命名

从 FLF API 2.0 起，所有 FLF API 组件使用四段版本号：

```text
FLFAPI主版本号.FLFAPI次版本号.FLFHMCL大版本号.HMCL次级版本号
```

示例：

```text
2.0.2.17
```

含义：

- `2`：FLFAPI 主版本号；API 接口发生破坏性变化时递增；
- `0`：FLFAPI 次版本号；兼容性小改动时递增；
- `2`：FLFHMCL Agent 的大版本号；
- `17`：HMCL 次级版本号；HMCL 3.17.x 为 `17`，HMCL 4.1.x 为 `1`。

Fabric 版本检测只比较前两段，因此同一个 API 主/次版本可以针对多个
FLFHMCL/HMCL 版本发布不同构建：

```text
2.0.2.16   # FLFHMCL 2 + HMCL 3.16
2.0.2.17   # FLFHMCL 2 + HMCL 3.17
2.0.3.17   # 同一 API，FLFHMCL 3 + HMCL 3.17
```

FLFHMCLauncher 使用后两段确认要下载哪个构建；HMCL/Fabric 只关心前两段
API 兼容性。

## 旧版本映射

历史版本按同一规则映射：

```text
1.1             -> 1.1.2.16
1.2.0-hmcl3.14  -> 1.2.2.14
1.2.0-hmcl3.15  -> 1.2.2.15
1.2.0-hmcl3.16  -> 1.2.2.16
```

下载链接仍指向旧资产；版本字段使用新的四段命名。
